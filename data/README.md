# Data Access Notice

This public repository includes selected district-level aggregated analytical outputs used to demonstrate and evaluate the GeoAI surveillance prototype. These outputs contain no person-level identifiers or individual case coordinates.

The underlying source surveillance records, restricted operational files and person-level health data are not distributed through this repository. Public files must not be used to attempt re-identification or treated as a substitute for authorised national surveillance data.

Access to restricted source data may be granted only for authorised academic review, dissertation examination or approved research purposes, subject to permission from the author and applicable data-governance requirements.
